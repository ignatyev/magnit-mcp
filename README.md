# Магнит UTCP — без кастомной веб-страницы

Магнит открывается **в официальном Chrome на Android**. Поиск, чтение и изменение
корзины выполняются через Chrome DevTools (ADB/CDP) и браузерный `fetch`.
Свой сайт на `127.0.0.1:8080` больше **не запускается**: вместо него используются
команды Termux и UTCP-инструменты. MCP-сервера, внешнего VPS и оплаты в сервисе нет.

## Установка и синхронизация

На телефоне нужны **Termux, Chrome, ADB, Node.js 22.13+ и Git**:

```sh
pkg update
pkg install nodejs-lts python git android-tools
git clone https://github.com/ignatyev/magnit-mcp.git
cd magnit-mcp
cp .env.example .env
```

Для уже установленного проекта достаточно `git pull origin main`.

В Android включите **Параметры разработчика → Беспроводная отладка**, один раз
сопрягите и подключите ADB (`adb pair`, `adb connect`). Убедитесь, что
`adb devices -l` показывает разрешённое устройство.

```sh
npm start
```

Команда откроет **официальный сайт Магнита в Chrome**. В этой вкладке выберите
«Экспресс» и откройте его корзину. Когда Chrome успешно прочитает корзину,
Termux сохранит подтверждённый сервис и `x-store-code` в зашифрованной сессии,
покажет результат и завершит команду. Никаких действий на отдельной
локальной странице выполнять не нужно. Синхронизацию можно повторить командой
`npm run sync`.

**Не используйте код из `formats.storeCode` вместо `x-store-code` запроса:**
они могут отличаться. По умолчанию режим — `express`, обычная доставка — `delivery`.
Только официальная корзина в Chrome подтверждает возможность безопасно
работать с выбранным сервисом.

## Команды Termux

```sh
npm run status
npm run debug
npm run tool -- search_products "молоко" 230668 express 20
npm run tool -- view_cart 230668 express
npm run logout
```

`npm run status` показывает состояние входа и код выбранного магазина без Cookie.
`npm run debug` собирает **один отчёт**: снимок Chrome, результаты чтения корзины,
различия транспортов/заголовков, каталог и журнал операций. Диагностические
операции не изменяют корзину. Чтобы сохранить чистый JSON:

```sh
node --env-file-if-exists=.env src/phone-cli.js debug > magnit-utcp-debug.json
```

Файл можно отправить в чат. Он не содержит значения Cookie, токены, адреса,
содержимое корзины и идентификаторы товаров. При возникновении ошибок
сначала проверьте `npm run status`, а затем пришлите диагностический JSON.

Для удаления только **локально сохранённой** сессии используйте `npm run logout`.
Авторизация в самом Chrome при этом сохраняется.

## Покупки через UTCP-агента

```sh
python -m pip install -r requirements.txt
export OPENAI_API_KEY="ваш API-ключ"
python agent.py "Найди молоко и добавь одну упаковку в корзину Экспресс"
```

OpenAI API оплачивается отдельно от подписки ChatGPT.
Агент использует `utcp-manual.json`, команды `src/tool-cli.js` и
официальный Chrome; **локальный HTTP-сервер не нужен**.

Пример ручной операции после проверки результатов поиска:

```sh
npm run tool -- add_to_cart "молоко" 230668 ID_ТОВАРА ID_ПРЕДЛОЖЕНИЯ 1 request-unique-001 express
```

Идентификаторы товара и предложения необходимо взять из фактического ответа
поиска. `request_id` должен быть уникальным для новой операции. Не повторяйте
неопределённую запись автоматически.

**Важно:** локальный CLI сам по себе пока не подключает телефон непосредственно
к текущему чату ChatGPT. Для управления из этого чата нужен отдельный
доступный коннектор или агентный мост. Пока можно работать с Termux и
`agent.py`.

## Как работает Chrome-транспорт

Каждая операция открывает временную вкладку `https://magnit.ru/` через
локальный ADB/CDP, выполняет разрешённые запросы в браузере с действующей
авторизацией, получает структурированный ответ и закрывает **только свою**
вкладку. При недоступности Chrome операция завершается ошибкой. Скрытого
возврата к проблемным прямым HTTP-запросам Node.js нет.

Существующие ограничения сохранены: строгая проверка сервиса и магазина,
допустимости товара, полное сохранение исходных позиций при PUT, журнал
идемпотентности, единственный PUT для изменения и независимый GET для
подтверждения результата. Смешанные и неоднозначные корзины не изменяются.
**Оплата и оформление заказа не поддерживаются.**

Реальная работоспособность новой схемы на телефоне должна быть подтверждена
чтением корзины через `npm run tool -- view_cart ...`, затем одним осторожным
добавлением. Если итог неоднозначен — проверьте официальную корзину и
не запускайте тот же запрос повторно.

## Ограничения

- Chrome и разрешённое беспроводное ADB-подключение должны оставаться доступными.
- Не передавайте файлы `.env`, `data/`, журналы с Cookie и токены.
- Магнит не предоставляет официальной гарантии совместимости этих веб-API.
- После некорректного ответа не очищайте журнал операций без проверки состояния корзины.
- Для исходного Node.js HTTP оставлены **только диагностические** запросы чтения.
