# Магнит с телефона — HTTP MCP

Исходный код: https://github.com/ignatyev/magnit-mcp. Сервис написан на Node.js и не использует Chromium, Playwright, ADB или автоматизацию браузера. Он предоставляет мобильную страницу каталога и MCP endpoint `/mcp`.

## Что работает в исходнике

- `magnit_status` сообщает реализованные возможности и их ограничения.
- `magnit_search_products` ищет по запросу, явному коду магазина и выбранному режиму каталога.
- `magnit_list_categories` получает категории для кода магазина и режима.
- Локальная страница `/` позволяет искать с телефона.

Вход в Магнит ID, SMS, корзина, оформление заказа и оплата не поддерживаются. Надёжный публичный HTTP-контракт для них не найден, поэтому соответствующих MCP-инструментов нет. Каталог использует сторонние, неофициальные описания API; текущая совместимость с серверами Магнит не проверялась. Официальный сайт ранее ответил `Forbidden`; сервис не обходит ограничения, не использует прокси или подмену устройства. Ответ `403` показывается как `access_restricted` без повторов.

Публичные реализации расходятся в контексте магазина. Клиент `3vgen/market-screening` использует `storeType: "1"`, `catalogType: "1"`; `1artik1/ComboPizzaSushiMCP` указывает для доставки `storeType: "dostavka"`, `catalogType: "3"`. В интерфейсе режим нужно выбрать явно. Цены ответа трактуются как копейки; неизвестные цены и остатки остаются неизвестными.

## Локальный запуск на Android через Termux

Требуется Node.js 22.13 или новее. Это локальная работа на телефоне, без отдельного ПК или VPS:

```sh
pkg update
pkg install nodejs-lts npm git
git clone https://github.com/ignatyev/magnit-mcp.git
cd magnit-mcp/bridge
cp .env.example .env
```

В `.env` оставьте `PUBLIC_BASE_URL=http://127.0.0.1:8080`, `HOST=127.0.0.1` и замените `MCP_BEARER_TOKEN` и `PHONE_ACCESS_SECRET` на разные случайные секреты длиной не менее 32 символов. Затем запустите:

```sh
npm start
```

Откройте `http://127.0.0.1:8080` на телефоне. Введите пароль самого сервиса, код магазина и запрос. Вводить пароль Магнит или SMS-код не нужно. Остановка процесса завершает локальный сервис.

Чтобы вызывать MCP из ChatGPT/Sites, нужен внешний HTTPS endpoint, доступный сервису Sites. Локальный адрес `127.0.0.1` снаружи телефона недоступен; настройка публичного HTTPS-доступа и заполнение Site runtime secrets выполняются отдельно. Не публикуйте HTTP-порт напрямую и не раскрывайте секреты.

## Docker на Linux

Для удалённого запуска нужен внешний TLS reverse proxy. Скопируйте `bridge/.env.example` в `.env`, задайте внешний HTTPS `PUBLIC_BASE_URL` и два отдельных случайных секрета, затем из `bridge/` выполните `docker compose up --build -d`. Конфигурация Compose не публикует HTTP порт напрямую и ожидает, что доверенный reverse proxy выставит `X-Forwarded-Proto: https` и перезапишет `X-Forwarded-For`.

В runtime secrets Site задайте `MCP_BRIDGE_URL=https://<домен>/mcp` и `MCP_BRIDGE_TOKEN` с тем же значением, что `MCP_BEARER_TOKEN`. Пока они не настроены, Site MCP сообщает `setup_required`.

## Проверки

Из каталога `bridge/`:

```sh
npm test
node --check src/server.js
```

Тесты используют имитацию ответов HTTP и не обращаются к Магнит. Они проверяют каталог, цены/остатки, размер ответа, ошибки/таймауты, секреты и синтаксис встроенного мобильного скрипта.
