# Магнит UTCP — полностью без MCP

В этой версии UTCP-клиент запускает локальные CLI-инструменты, а Node.js напрямую выполняет HTTPS-запросы к API Магнита. MCP-сервера, VPS, удалённого моста и проксирования вызовов агента нет. Локальный HTTP-сервис существует только для входа в Chrome и мобильной страницы.

## Установка на Android в Termux

Требуются Node.js >=22.13, Python, Chrome, ADB и Git.

    pkg update
    pkg install nodejs-lts python git android-tools
    git clone https://github.com/ignatyev/magnit-mcp.git
    cd magnit-mcp
    git checkout migration/utcp-direct-agent
    cp .env.example .env
    npm test
    npm run check
    npm start

В Android включите Параметры разработчика -> Беспроводная отладка. Выполните adb pair и adb connect, используя показанные Android адреса и порты. Проверьте adb devices -l. Откройте на этом же телефоне http://127.0.0.1:8080 и нажмите Войти в Магнит. Ввод телефона, SMS и CAPTCHA — только в официальном Chrome.

Найдите код express-магазина (4–8 цифр) и выполните поиск. Активный адрес аккаунта автоматически не выбирает магазин.

## Миграция сохранённой сессии

В прежней установке файлы находились в bridge/data/. До удаления старого проекта перенесите owner-key, magnit-session.enc и cart-operations.enc в новый каталог data/. Ключ шифрования должен совпасть; иначе сессия недоступна. Устаревшее PHONE_ACCESS_SECRET могло использоваться как ключ, поэтому перед миграцией проверьте, какой именно секрет использовала прежняя установка.

## UTCP агент

    python -m pip install -r requirements.txt
    export OPENAI_API_KEY="ваш-ключ"
    python agent.py "Найди продукты к завтраку и собери корзину"

ChatGPT Plus не включает OpenAI API. Агент использует Python UTCP client + utcp-cli и локальный utcp-manual.json. CLI-инструменты связываются с Магнитом непосредственно, не используя локальный HTTP-сервер.

Мобильная страница также содержит текстовое поле для обращения к этому агенту (после установки Python-зависимостей и ключа).

Инструменты без модели:

    npm run tool -- status
    npm run tool -- search_products "молоко" 12345 express 10
    npm run tool -- view_cart 12345

Замените 12345 на код выбранного магазина.

## Ограничения

- Для add/set заново выполняется поиск в express каталоге и проверяется соответствие ID. Весовые и ограниченные товары не добавляются.
- Каждая запись требует request_id, операция защищена зашифрованным журналом и локальной межпроцессной блокировкой.
- После неопределённого исхода нельзя автоматически повторять запись; сначала перечитайте корзину. Если процесс аварийно завершился и остался data/cart.lock, убедитесь, что записывающий процесс не работает, и проверьте корзину перед удалением блокировки.
- Нельзя исключить одновременные изменения корзины официальным приложением.
- Оформление и оплата не поддерживаются, суммы lite — не окончательная стоимость.
- API Магнита основаны на неофициальных наблюдениях. Реальная доступность и вход на Android здесь не проверены. Ошибки 403 не обходятся.
- Интерфейс доступен только локально на 127.0.0.1. Не публикуйте файлы .env, data/ и Cookie.
- ChatGPT в текущем чате не умеет подключать локальный UTCP-манифест; запускайте агент отдельно на своём устройстве.

## Тестирование

npm test запускает синтетические тесты модулей API, корзины и входа; npm run check проверяет Node-синтаксис. Это не заменяет проверки на устройстве.
